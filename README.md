An entry for the [Invent a Word We Need](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0) bounty on make.fun: it coins one brand-new English word for a familiar everyday moment that English has never named, and defines it in a single clear line of at most 140 characters. The word is built from familiar parts so it is easy to say, spell and remember, and the definition lands in one reading.

## Run it

```sh
python3 main.py
```

This writes the one-line entry to `/output/entry.txt` — exactly one line, no trailing newline.
